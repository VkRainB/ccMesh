# 同步

同步模块负责配置与数据的备份、恢复、导出，并支持通过 WebDAV 实现跨设备同步。

![同步](/screenshots/sync/sync.png)

## 本地备份与恢复

- **创建备份**：把当前配置与数据打包为一个本地备份。
- **恢复备份**：从历史备份中选择一份还原，覆盖当前状态。
- **备份列表**：管理已有备份，查看时间并按需删除。

适合在重大变更（如批量调整端点、切换渠道）前先做一次快照。

## 导出

把配置 / 数据导出为文件，便于：

- 在另一台机器上导入；
- 归档或分享配置模板（注意密钥等敏感信息）。

## WebDAV 远程同步

配置 WebDAV 服务后，可把备份同步到远程，实现多设备之间的配置一致性：

1. 填写 WebDAV 服务地址与凭据。
2. 把备份上传到远程 / 从远程拉取。

这样换设备或重装系统时，能快速恢复整套 ccMesh 配置。
