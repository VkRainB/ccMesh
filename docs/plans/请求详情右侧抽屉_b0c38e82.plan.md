# ccMesh：请求详情右侧抽屉、分行时间与统一宽度的实时监控

对照 cc-switch 的 `RequestDetailPanel.tsx` 与 `RequestLogTable.tsx`。只改 [RequestMonitor.tsx](src/components/business/RequestMonitor.tsx)、[format.ts](src/lib/format.ts)、[EndpointStatsTable.tsx](src/pages/Statistics/_components/EndpointStatsTable.tsx) 及关联检查；新增请求详情组件。已确认只覆盖实时监控和统计页的端点请求记录，本机 OMP/Claude Code/Codex 用量及 Cursor 账单的兄弟实现保持原样。`F:/IT/cc-switch` 全程只读；Dashboard 独立加宽方案已按用户最终要求撤回。

## 1. 时间分行与今天省略日期

当前 `RequestMonitor.tsx:334-340` 用 `fmtDateTime(log.ts)` 在同一行显示完整日期和时间。改为：

- 今天：只显示「21:39:33」，不显示日期，也不保留空白日期行。
- 非今天：第一行「2026-11-06」，第二行「21:39:33」。日期用次级文字，时间用等宽数字；两行分别不换行。
- 今天按浏览器本地日历判断，与 `range.ts:21-25` 的 `startOfTodayMs` 对齐，不按 UTC 日期、最近 24 小时或渠道计价时区判断。
- 时间格沿用完整时间的悬停提示；抽屉仍显示完整日期时间，不省略今天的日期。
- 将 `fmtTime`、`fmtDateTime` 从 `RequestMonitor.tsx:213-230` 移到已有 `lib/format.ts`，表格和抽屉复用。日期复用 `range.ts:49-55` 的 `ymd`，删除重复的 `fmtDate`，更新调用方与测试导入，不保留旧导出别名。
- `RequestMonitor` 维护一份当天零点状态，传给表格判断；本地次日零点安排一次更新，窗口重新聚焦、页面恢复可见时校正。按日历计算下一天，不用固定加 86,400,000 毫秒；每行不建定时器，卸载时清理监听与定时器。
- 现有日期筛选继续使用稳定的当天零点，不把持续变化的当前毫秒放进查询键。跨日后即使没有新请求，昨天的行也补回日期。

## 2. 统一宽度与列宽分配

已确认：用户查看独立加宽效果后要求恢复统一宽度。原先「拆分卡片与实时监控宽度」的方案作废，`Dashboard/index.tsx` 已恢复原样。

- 标题、`ServiceCard`、三张统计卡和实时监控继续共用原有 `max-w-5xl` 容器，左右对齐。不修改全局页面边距，不使用负边距扩宽。
- 保留时间分行和模型映射两行的紧凑展示，不恢复原先被挤到 66 px、短模型名断词的列布局。
- `RequestLogTable` 保留 `overflow-x-auto`，外层补齐 `min-w-0`；内容放不下时只在表格内部滚动，不让整页横向溢出。不再保留行末详情图标及其空白表头。
- 按用户最终要求，`COLUMNS` 的最小宽度（rem）同时作为伸展权重，`RequestLogTable` 使用原生 `table-fixed`，只按当前可见列的权重总和分配百分比宽度。关闭任意字段时，释放的空间分配给所有剩余列，不再只由端点列吸收；窄于最小宽度总和时，仅表格内部横向滚动。
- 原先模型列 `12rem` 上限及名称容器 `w-40` 作废。模型、路由、金额和延迟内容随各自列宽伸缩，长文本继续 CSS `truncate`，不按字符数截取；正常短名不拆词，完整模型名与路由可悬停或在抽屉查看。不缩小全表字号，不增加 DOM 测量。
- `ModelCell` 的映射链由「请求名 / 独占一行的箭头 / 实际名」收为两行：请求名一行，箭头与实际名同一行。「仅显示实际模型」仍是一行；空值与回退规则保持原样。
- 按用户最终要求，入站与出站合并为「入站 / 出站」一列，第一行入站路径、第二行出站路径；保留入站协议及出站完整地址的悬停提示，沿用旧记录的 `inferPath` 回退。两行分别 CSS 省略，不扩大页面宽度。配置使用单一 `routes` 开关，旧 `inbound/outbound` 键由现有过滤器移除，其余偏好保持原样。
- 按用户最终要求撤下独立「成本」列及配置开关。Token 第一行保留数量和用量提示，第二行展示价格或未计价状态，两行像延迟列一样左对齐；点击第二行打开详情。显隐统一跟随 Token，旧缓存中的 `cost` 由现有 `parsePreferences` 过滤，不新增兼容分支。
- 统计页复用上述时间与列布局，但 `Statistics/index.tsx` 的整体最大宽度不扩大，避免连带改变趋势、用量与账单布局。
- 按用户追加要求，`EndpointStatsTable.tsx` 删除「计价覆盖率」整列及「已计价 / 未计价」数量展示，只保留成本；内部已计价计数继续用于区分真实免费与未知金额，不改计费或存储。

新增 `src/components/business/RequestDetailSheet.tsx`：

- 复用 `components/ui/dialog.tsx` 已导出的 `Dialog`、`DialogPortal`、`DialogOverlay`、`DialogHeader`、`DialogTitle`、`DialogClose`；右侧内容使用已安装 `radix-ui` 的 Dialog Content。只在业务组件中定义右侧样式，不复制 cc-switch 整套 Sheet、不新增依赖、不改其他弹窗的居中行为。
- 桌面抽屉目标宽度 560 px，最大不超过视口，窄窗口占满可用宽度；右侧进入，标题固定，正文 `min-h-0 flex-1 overflow-y-auto`，长内容不遮住关闭按钮。沿用本项目主题色、边框与模态遮罩，不搬迁 cc-switch 的窗口栏系统。
- 标题原文「请求详情」，关闭按钮无障碍名称「关闭请求详情」；支持关闭按钮、Esc、点击遮罩关闭，Tab 焦点留在抽屉内，减弱动画偏好下不做滑入动画。

## 4. 行入口、选择态与关闭行为

在 `RequestMonitor.tsx:72-105` 增加 `selectedLog: RequestLog | null`，每个监控实例只挂一个抽屉；在 `172` 的表格调用、`188` 的 `RequestLogTable` 和 `324` 的 `RequestRow` 传递打开回调，Dashboard 与 EndpointStatsPanel 的数据调用方式不变。

- 点击行内非交互区域或 Token 第二行价格打开同一个抽屉，不保留独立成本浮层。表格配置继续沿用原 Popover。
- 按用户最终要求移除每行末尾的详情图标按钮与占位列。请求行设置 `tabIndex=0`，Enter/Space 打开详情；隐藏时间或 Token 后仍可访问。保留原生 table/tr 语义，子按钮的键盘事件不重复触发行入口。
- Token、错误悬停入口保持快捷查看，点击这些控件不冒泡打开抽屉；拖选文本也不触发行点击。行悬停和按钮焦点给出轻量反馈。
- 选择时保存该行不可变对象引用，不深拷贝，不按数组下标追踪。实时列表刷新、插入或移出当前页时，抽屉继续显示原记录，不跳到新请求、不被新费率覆盖；不依赖列表里持续存在同一个 ID。
- 切换分页、筛选、端点过滤、模式或页面时关闭；清理成功在现有 `onCleaned` 回调里清空选择。`hideWhenEmpty` 的提前返回须考虑已打开的抽屉，不能因后台列表暂空突然消失或留下以后重新冒出的选择态。
- 打开时记录实际触发元素，关闭时恢复焦点；原行因实时刷新被移除时，回退到该监控的「配置请求表格」按钮，不把焦点留在已卸载节点。关闭后保留页码、筛选与列表滚动位置。
