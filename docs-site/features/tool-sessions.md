# 会话管理工具

**会话管理** 列出本机 Claude Code / Codex 写入磁盘的工具会话文件，供浏览与清理。页面说明：与应用内对话无关。

入口：侧栏对应项，或从 **对话** 页眉点 **会话管理**。

## 浏览会话

1. 用提供方筛选：**Claude** / **Codex**（或全部）。
2. 在列表中选择会话，右侧查看消息与目录。
3. 可按关键字过滤列表。

未找到会话时，确认本机已产生过 Claude Code / Codex 历史。

## 删除工具会话文件

可单删或多选删除。确认框写明：将从磁盘删除工具会话文件（Claude 会一并删除 sidecar），此操作不可恢复。

删除不影响 **对话** 页里的话题库，也不删除端点或配置文件渠道。

## 与对话页的边界

| | 对话 | 会话管理 |
|--|------|----------|
| 数据 | CC Mesh 内置 Chat DB | 本机工具会话文件 |
| 用途 | 连通性试探 | 浏览 / 清理 CLI 历史 |
| 工具调用 | 无 | 展示工具侧已有内容 |
