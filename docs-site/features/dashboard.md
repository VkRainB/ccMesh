# 如何使用仪表盘

仪表盘是主控制台：左侧看端点队列，右侧启停本地代理，下方跟进实时请求。

![仪表盘](/screenshots/dashboard/index.png)

## 端点队列

左卡 **端点队列** 列出全部启用端点：快速队列成员在前（闪电标记），其余按全局排序。当前工作端点会高亮；熔断 Open / HalfOpen 时状态点变色，悬停可看原因。

只有代理运行中才会高亮当前端点。高亮优先取最近一条请求明细的端点名，没有则回退代理状态里的当前端点。

## 编辑快速队列

1. 点击端点队列标题旁的闪电图标，打开 **编辑快速队列**。
2. 从右侧 **启用队列** 拖入左侧，或双击切换。
3. 在快速队列内拖动调整优先顺序；拖回启用队列或点 × 移出。

只要存在至少一个快速队列成员，代理选路只轮询快速队列；全部移出后回退全部启用端点。数字与算法见 [轮换与熔断如何工作](/advanced/rotation)。已启用端点也可在编辑表单打开 **加入快速队列**。

## 本地代理

右卡 **本地代理**：

1. 用开关启动或停止服务。
2. 点击 **端口** 数字跳到设置改监听端口。
3. 点复制图标复制 `http://127.0.0.1:<端口>`。

代理未运行时，客户端请求不会经 ccMesh 转发。

## 今日概览

页面中部展示当日 Token 与请求量等概览卡片。

## 实时请求监控

代理运行期间，每条经网关的请求出现在列表中，常见列包括：

- 模型
- 耗时
- 首字延迟（TTFT）
- Token 明细（输入 / 输出等）

这与 **统计 → 端点统计** 里的区间监控同源事件，但仪表盘侧重当前会话。历史与周期聚合见 [如何查看统计](/features/statistics)。应用运行日志（非请求明细）见 [如何查看运行日志](/features/logs)。
