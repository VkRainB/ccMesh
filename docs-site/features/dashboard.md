# 仪表盘

仪表盘是 ccMesh 的主控制台，集中展示代理服务状态、今日用量概览与实时请求监控。

![仪表盘](/screenshots/dashboard/index.png)

## 代理服务控制

- **启停代理服务**：一键开启 / 关闭本机的本地代理服务。
- **端口与状态一览**：实时显示监听端口与运行状态，方便把客户端指向正确的地址。

只有在代理服务运行时，客户端的请求才会被 ccMesh 接管、转换并转发到上游。

## 今日概览

- **今日 Token 用量**：当天累计的 Token 消耗概览。
- **请求概览**：当天请求量等关键指标。

## 实时请求监控

代理服务运行期间，每条经过 ccMesh 的请求都会实时出现在监控列表中，展示：

- **模型**：本次请求使用的模型名。
- **耗时**：请求总耗时。
- **首字延迟（TTFT）**：从发起到收到首个响应片段的延迟，衡量流式响应体验。
- **Token 明细**：输入 / 输出等 Token 数量。

这让你可以在调试客户端、切换上游时第一时间看到效果与异常。
