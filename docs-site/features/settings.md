# 如何调整设置

**设置** 页用五张卡片管理全局选项。改端口或代理后，按提示重启代理使监听端口生效。

![设置](/screenshots/settings/settings.png)

## 常规选项

| 项 | 作用 |
|----|------|
| **代理端口** | 本地代理监听端口（与仪表盘显示一致） |
| **主题** | 跟随系统 / 浅色 / 深色 |
| **定时自动切换主题** | 打开后设置浅色与深色起始时间 |
| **语言** | 中文 / English |
| **关闭窗口行为** | 每次询问 / 最小化到托盘 / 直接退出 |
| **日志级别** | 写入配置并同步日志页捕获等级：`trace` / `debug` / `info` / `warn` / `error` |

## 启动行为

| 项 | 作用 |
|----|------|
| **自启动** | 跟随系统开机启动 |
| **静默启动** | 启动时不展示窗口，常驻托盘 |
| **自动运行** | 应用打开时自动启动代理服务 |

## 系统 / 高级

自定义出站 User-Agent：

- **OpenAI 通用端点 UA**：清空则透传客户端 UA
- **Claude 端点 UA**：清空则透传客户端 UA

字段旁提示给出参考示例字符串。

## 代理

全局出站代理影响转发、拉取模型，以及可选的应用更新下载。

| 项 | 作用 |
|----|------|
| **启用代理** | 全局 `proxyEnabled` |
| **代理服务器** | 如 `http://127.0.0.1:7890`；可点 **测试** |
| **代理更新** | `proxyForUpdate`；仅在全局启用时代码可选，用于检查与下载更新 |

转发与拉取模型的真值（与端点开关组合）：

```text
proxy = (端点 useProxy || 全局 proxyEnabled) && proxyUrl 非空
```

URL 为空时一律直连。端点侧开关见 [如何配置上游端点](/features/endpoints)。
