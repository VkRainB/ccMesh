# 配置文件

配置文件模块以「渠道」的方式管理 AI 工具的本地配置，让你无需手工编辑 JSON / TOML 即可在多套配置之间切换。

![配置文件](/screenshots/config-profiles/profiles.png)

## 支持的工具

- **Claude Code**：管理其 `settings.json`。
- **Codex**：管理其 `auth.json` + `config.toml`。

## 渠道（Channel）

一个「渠道」就是一套面向某个工具的完整配置。你可以：

- 创建多个渠道（例如不同上游、不同模型组合）；
- 在渠道之间快速切换、应用；
- 把当前生效的配置保存为渠道。

## 两种写入模式

配置文件支持双模式，覆盖「直接接 ccMesh 端点」与「完全自定义」两类需求：

- **端点写入**：选择 ccMesh 中已配置的端点，自动把对应的 Base URL / Key 等写入工具配置。
- **自定义写入**：直接编辑完整配置内容，适合需要精细控制的高级场景。

## 表单与 JSON 双向联动

编辑配置时，**表单字段** 与 **JSON / TOML 原文** 双向同步：

- 在表单中修改字段，原文实时更新；
- 直接编辑原文，表单随之回填。

内置基于 CodeMirror 的编辑器提供语法高亮与校验体验。

## 保存与应用分离 · 自动备份

- **保存渠道** 与 **应用覆写** 是两个独立动作：保存只是把配置记录到 ccMesh，应用才会真正写入工具的配置文件。
- **应用前自动备份**：覆写工具配置前，ccMesh 会先备份原有配置，避免误覆盖导致不可恢复。

## 典型流程

1. 在 [端点管理](./endpoints) 中配置好上游端点。
2. 在配置文件中新建渠道，选择「端点写入」并关联该端点。
3. 核对表单 / 原文无误后，点击应用，把配置写入 Claude Code / Codex。
4. 启动客户端验证；如需切换上游，回到此处切换渠道并重新应用即可。
