# 如何管理精灵宠物

**精灵宠物** 管理桌面宠物资源。从 **设置 → 宠物 → 打开** 进入（侧栏也可链到本页说明）。

## 导入宠物资源

1. 在网格中选择 **导入文件夹** 或 **导入 zip**。
2. 在系统对话框中选资源；成功后列表出现新项并自动选中。

## 选中并激活宠物

1. 点击网格中的宠物卡片选中（高亮表示当前选择，未必已激活）。
2. 若选择与当前激活不同，底部 **保存** 可用。
3. 点 **保存** 后才切换桌面宠物激活状态。

仅选中不保存不会改激活项。可用 **刷新列表** 重新扫描资源。

## 删除宠物资源

删除前确认。操作不可恢复；若删除的是当前激活宠物，会同时取消桌面宠物激活。
