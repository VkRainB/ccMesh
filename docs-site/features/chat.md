# 如何用对话试探连通性

**对话** 对本机已配置端点做连通性试探。界面提示：非核心功能，对话无工具支持。

## 试探前需要什么

1. 在 [端点管理](/features/endpoints) 配置端点并 **点亮** 至少一个模型（或填写锁定模型）。
2. 建议已启动本地代理；对话经应用内通道访问端点配置。

无可用模型时，页眉显示 **去配置端点**。

## 发一条试探消息

1. 打开 **对话**。
2. 在页眉模型选择器中选「端点 + 模型」。
3. 输入消息发送；流式回复出现在气泡中。
4. 可新建话题、重命名、删除话题；支持中止生成、重新生成与分支切换。

模型列表只包含点亮（或锁定）后对外可用的模型。

## 与会话管理的区别

页眉 **会话管理** 打开的是本机 Claude Code / Codex 工具会话文件浏览器，不是本页的对话数据库。详见 [如何管理本机工具会话](/features/tool-sessions)。
