# 如何备份与同步配置

**同步** 页从上到下包含：cc-switch 迁移、WebDAV、远程备份列表、本地备份。

![同步](/screenshots/sync/sync.png)

## 从 cc-switch 迁移

若本机装过 cc-switch，可把可识别的 Claude / Codex 供应商导入为 ccMesh 端点。

1. 点击 **同步配置**，打开 **cc-switch 配置迁移**。
2. 等待预览：可读项标为可勾选；OAuth、托管账号、缺 URL/密钥等会标为跳过并说明原因。
3. 按需用 **仅显示 Claude** / **仅显示 Codex** 筛选，全选或逐项勾选。
4. 点击 **导入 N 项**。完成后查看提示中的成功数、启用数与跳过数。

无模型清单的导入项可能以未启用状态入库，需在 [端点管理](/features/endpoints) 补全并启用。

## WebDAV

1. 填写 WebDAV 地址、用户名与密码（匿名可留空用户名）。
2. 远程备份落在服务端 `ccMesh/` 目录下的 `.db` 文件。
3. 用测试连接确认可达，再上传或从列表下载。

## 远程备份列表

连接成功后列出远程 `.db` 备份（按修改时间倒序）。可下载恢复或删除远程文件。

## 本地备份与恢复

- **创建备份**：把当前配置与数据打成本地快照。
- **恢复备份**：选一份历史备份覆盖当前状态。
- **备份列表**：查看时间并按需删除。

重大变更（批量改端点、切换渠道）前建议先建一份本地备份。导出文件含密钥等敏感信息，分享前自行脱敏。
