# 统计

统计模块汇总历史用量，帮助你了解 Token 消耗与各上游端点的使用情况。

![统计](/screenshots/statistics/statistics.png)

## 多维度用量

可按以下维度查看历史用量：

- **按应用**：区分 Claude Code、Codex 等不同客户端来源的消耗。
- **按端点**：每个上游端点承接的请求量与 Token 消耗。
- **按模型**：各模型的用量分布。

## 用量面板

汇总面板展示总体用量与趋势，并可对比不同周期的变化（趋势徽章直观标注上升 / 下降）。

![端点维度统计](/screenshots/statistics/statistics2.png)

## 端点维度分析

端点统计表按端点列出请求量、Token 等指标，便于识别：

- 哪些端点是主力承载；
- 哪些端点几乎没有流量或异常偏高；
- 是否需要调整端点顺序或映射。

## 历史明细

支持查看更细粒度的历史记录，回溯特定时间段的用量情况。
