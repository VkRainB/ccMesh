# 如何查看运行日志

**日志** 显示应用 tracing 捕获的运行日志，默认环形缓冲约 500 行。它不是仪表盘或统计里的请求明细表。

## 过滤与捕获工具栏

1. 点级别芯片过滤（可多选）；**全部** 清空级别筛选。
2. 在关键字框输入文本，匹配 message、target 与结构化字段。
3. 用 **捕获等级** 下拉设置最低捕获级别（`trace` / `debug` / `info` / `warn` / `error`）。设置页的 **日志级别** 与此同步。
4. **复制** 当前过滤结果；**清空** 清空缓冲。

低于 WARN 时，降噪过滤会去掉第三方框架噪音（如 GUI / HTTP 栈）；本项目模块日志不受影响。

## 日志阅读列表

每行含时间、级别、target、消息与字段。停留在列表底部时自动跟随新日志；上滚后出现 **回到底部**。

## 与请求监控的区别

| 表面 | 内容 |
|------|------|
| 本页日志 | 应用内部 tracing 事件 |
| 仪表盘 / 端点统计监控 | 经代理的 HTTP 请求明细（模型、耗时、Token） |

排查转发失败时可两页对照。
