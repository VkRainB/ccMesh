# 第一次把请求跑通

本节用最短路径，带你从打开应用到客户端成功调用。需要截图逐步对照时，改走 [快速入门](/guide/quickstart)。

## 安装与上游凭证

- 已安装 ccMesh，见 [如何安装 ccMesh](/guide/installation)
- 手头有一个可用的上游 API 地址与密钥

## 1. 启动本地代理

1. 打开 **仪表盘**。
2. 打开右侧 **本地代理** 开关。
3. 记下显示的端口（默认本机 `http://127.0.0.1:<端口>`）。

详见 [如何使用仪表盘](/features/dashboard)。

## 2. 添加一个端点

1. 打开 **端点管理**，点击 **+ 新建端点**。
2. 填写 **名称**、**API URL**、**API Key**。
3. 按上游协议选择 **转换器**：`claude` / `openai` / `codex`。
4. 拉取或手输 **模型清单**，按需点亮对外公布的模型。
5. 点 **保存**，再点卡片上的连通性测试。

字段与点亮规则见 [如何配置上游端点](/features/endpoints)。协议互转细节见 [请求如何在协议间转换](/advanced/protocol-transform)。

## 3. 让客户端指向 ccMesh

推荐用 **配置文件** 写入 Claude Code / Codex / Claude Desktop（应用前自动备份）。见 [如何用配置文件接入客户端](/features/config-profiles)。

也可手动把客户端的 Base URL 设为 `http://127.0.0.1:<端口>`。本地代理默认不校验客户端密钥，可留空或填任意值。

## 4. 发一条请求并核对

在客户端发起一次对话。回到仪表盘 **实时请求监控**，应看到模型、耗时、首字延迟与 Token。累计数据在 **统计**。

可选：在 **同步** 做本地或 WebDAV 备份，见 [如何备份与同步配置](/features/sync)。
